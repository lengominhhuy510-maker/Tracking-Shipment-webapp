# Decisions

This directory contains decision records. Each decision is a file named
`<decision-id>.md` (for example `0001-auth-boundary.md`).

Decision records are created during `/harness-intake` when a durable decision is
made — a choice about behavior, architecture, authorization, data ownership, API
shape, audit/security, or validation requirements that future work should
inherit. Use `docs/templates/decision.md`. A note inside a story or trace is not
a durable decision record.
